## Описание

Программа представляет собой TCP-сервер, который:
загружает базу пользователей из текстового файла;
обеспечивает подключение клиентов в течение всего времени функционирования;
обрабатывает запросы клиентов в однопоточном режиме;
проводит идентификацию и аутентификацию клиента по схеме `LOGIN || SALT16 || SHA256(SALT16 || PASSWORD)`;
принимает векторы чисел с плавающей точкой и возвращает сумму их квадратов;
записывает информацию об ошибках и работе в лог-файл.

## Требования к среде

ОС: Linux (Ubuntu/Debian и производные);
Компилятор: `g++` с поддержкой C++17;
Библиотеки: 
 `libboost-program-options-dev`;
 `libcrypto++-dev`;
 `make`.
